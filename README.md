Entry for the [make.fun](https://make.fun/competitions/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610) competition **One-Line Roast: The Gadget You Use Every Day** — one original line (max 200 characters) roasting a gadget or app used every day.

## How it works

`main.py` is deterministic: it writes a single roast line to `/output/entry.txt` (UTF-8, 1–200 characters). The line was chosen from 36 original candidates through blind two-way duels judged against the competition's published judge criteria (funny, fresh, neatly worded, specific to one daily gadget).

## Run

```sh
python3 main.py
cat /output/entry.txt
```

No network access, no dependencies, no arguments. Runs in well under 60 seconds.
